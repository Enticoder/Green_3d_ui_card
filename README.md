## 🌟 About the Project

A beautiful, modern **3D Glassmorphism UI Card** featuring layered ripple effects, smooth hover animations, and interactive social buttons. Perfect for portfolio websites, product showcases, or dashboard components.

This card uses pure **CSS 3D transforms** (`preserve-3d`, `rotate3d`, `translate3d`) and **backdrop-filter blur** to create a stunning depth effect without any JavaScript.

## ✨ Features

- 🎨 **Vibrant Mint Green Gradient** — Eye-catching linear gradient background
- 🌊 **Layered Ripple Circles** — 5 concentric circles with blur effect for depth
- 🪟 **Glassmorphism Design** — Frosted glass effect with translucent layers
- 🎭 **3D Hover Animation** — Card tilts on hover (`rotate3d(1, 1, 0, 30deg)`)
- 🎯 **Interactive Social Buttons** — Instagram, Twitter, Discord with hover states
- ⚡ **Staggered Animations** — Elements animate with delays for a cinematic feel
- 📱 **Responsive Design** — Scales beautifully on any screen size
- 🔧 **Zero JavaScript** — Pure CSS magic!
